## Executive Overview

High-end safari logistics across the East African wilderness (Masai Mara, Serengeti, Amboseli, Tsavo, Samburu, and Lake Nakuru) operate in one of the most demanding environments on earth:

* **Extreme Connectivity Gaps:** Cellular dead zones leave custom 4x4 cruisers and field teams isolated across deep-bush game drives.
* **Complex Fleet Dynamics:** Fleets endure punishing terrain, demanding proactive mechanical stress monitoring, fuel consumption analysis, and strict speed-governor enforcement.
* **Bespoke Guest Expectations:** Ultra-high-net-worth (UHNW) itineraries involve intricate multi-leg bush flights, private tent allocations, VIP immigration manifests, and custom game excursions.
* **Wildlife & Conservation Compliance:** Real-time movement tracking must strictly respect conservancy boundaries, migration corridors, and anti-poaching ranger protocols.

**Axelo Safari Suite** is an enterprise-grade digital platform engineered specifically to unify remote fleet telemetry, offline satellite emergency response, lodge reservations, and ecological intelligence under a single, military-grade interface.

### 1. SOS Emergency Network & Ranger Mesh
* **Cellular-to-Satellite Fallback:** Instant failover to low-latency RF mesh networks and Iridium satellite uplinks when leaving cellular range.
* **One-Click Silent Distress:** Tactically positioned distress triggers for drivers with encrypted coordinate broadcasting.
* **Ranger Dispatch Desk:** Direct coordinates delivery to Kenya Wildlife Service (KWS) and local conservancy ranger squads.

### 2. Live Telemetry & Operations Watchdog
* **Vehicle Diagnostics Stream:** Continuous monitoring of radiator temperatures, oil pressure, engine RPM, and tire load indices.
* **Automated Geofencing:** Real-time alerts on unmapped trail deviations, park boundary breaches, or animal buffer zone intrusions.
* **Speed & Terrain Compliance:** Black-box telemetry tracking driving behavior across sensitive savanna ecosystems.

### 3. Connected Fleet Workspace & Dispatch
* **Driver & Guide Manifests:** Digital rosters syncing safari drivers, city transfer chauffeurs, and professional naturalists.
* **Fuel Telemetry:** Digital tank sensor integration to monitor fuel reserves against remote airstrip replenishment points.
* **Inter-Vehicle Comms:** Outpost dispatch dashboard connecting camp head-guides with field cruiser teams.

### 4. High-Conversion Luxury Reservation Suite
* **Dynamic Suite Allocation:** Season-aware room grid management for luxury tented camps and private safari villas.
* **Bush Flight Coordination:** Inbound/outbound charter flight manifest syncing with bush airstrips (Wilson, Mara Serena, Musiara).
* **Agency Commission Ledgers:** Transparent B2B tour operator and agency rate calculation engine.

### 5. Savanna Micro-Climate Radar
* **Hyper-Localized Weather Grids:** Onsite sensor feeds detailing barometric drops, sudden squalls, and flash flood indicators.
* **River Crossing Safeties:** Predictive flood stage monitoring along the Mara and Talek river banks during migration crossings.
* **Sun Index & Heat Planning:** Solar intensity metrics assisting guides in planning morning and evening game drive timing.

### 6. L6 High-Security Logs & Conservation Intelligence
* **Cryptographic Audit Trails:** Immutable tamper-evident logging of client passenger manifests, permits, and payment transactions.
* **Wildlife Migration Sighting Logs:** Guide-reported big cat sightings and migration movements mapped without public radio leakage.
* **Zero-Trust Access Architecture:** Strict role-based permission tiers (Ranger, Camp Manager, Head Guide, Executive Dispatch).

## API Contracts & Booking Pipeline

### Operator Briefing Request (`POST /api/bookings`)

Submits an enterprise tour operator demo request. Every submission runs through runtime validation and dual-path persistence:

#### Request Body
```json
{
  "name": "David Lekishon",
  "email": "david@maraexpeditions.co.ke",
  "phone": "+254712345678",
  "company": "Mara Expeditions Ltd",
  "safariDrivers": "12",
  "cityDrivers": "4",
  "guides": "8",
  "preferredDate": "2026-10-15",
  "notes": "Transitioning 16 Land Cruisers to satellite tracking before the migration peak."
}
```

#### Dual-Path Execution Flow
1. **Schema Validation:** Evaluated server-side using Zod (`bookingSchema`). Rejects invalid phone numbers, staff counts, or malformed emails with HTTP 400.
2. **Local Fallback Persistence:** Writes transaction record directly to `lib/db/bookings.json` with generated reference `BK-XXXXXX-XX`.
3. **Resend Email Dispatch:** Generates a branded HTML operational briefing transmitted to `concierge@axelosafari.com`.
4. **Response:**
   ```json
   {
     "success": true,
     "bookingId": "BK-829104-42",
     "emailDispatched": true,
     "localPersisted": true,
     "message": "Briefing request submitted and Operations team notified."
   }
   ```

## Getting Started

### Prerequisites
* **Node.js:** `v18.17.0` or later
* **Package Manager:** `npm`, `pnpm`, or `bun`

### 1. Clone the Repository
```bash
git clone https://github.com/Manukyalo/Axelo-safari-suite.git
cd Axelo-safari-suite
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` into `.env.local`:
```bash
cp .env.example .env.local
```

Populate the required configuration values:
```ini
# Production Site URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# Direct Concierge WhatsApp Hotline (Include country code)
NEXT_PUBLIC_WHATSAPP_NUMBER=+254731237251

# Resend API Key for Booking Briefing Dispatch
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxx
```

### 4. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Security & Deployment Considerations

* **SSR De-synchronization Prevention:** Heavy visual components (`HeroScene3D`, `Lenis`, `GSAP` animations) are wrapped via `next/dynamic` with `{ ssr: false }` to prevent hydration mismatches.
* **Strict Parameter Sanitization:** All inbound contact data is sanitized; user notes are escaped prior to rendering in HTML email templates to mitigate injection vectors.
* **Environment Separation:** Secret keys (`RESEND_API_KEY`) reside exclusively on the server layer and are never exposed through `NEXT_PUBLIC_` prefixes.
